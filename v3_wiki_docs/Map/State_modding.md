# State modding

From Victoria 3 Wiki

[Jump to navigation](#mw-head) [Jump to search](#searchInput)

 

Please help with verifying or updating older sections of this article.  
At least some were last verified for [version](/Victoria_3_Wiki:Versioning "Victoria 3 Wiki:Versioning") 1.9.

[States](/States "States"), or more properly state regions, are defined parts of the game map which contain pops and buildings, and are the primary layer for interactions on the map. State regions are defined in map\_data/state\_regions.

## Example state region\[[edit](/index.php?title=State_modding&veaction=edit&section=1 "Edit section: Example state region") | [edit source](/index.php?title=State_modding&action=edit&section=1 "Edit section: Example state region")\]

State regions are defined as a list of 'provinces', along with several characteristics.

STATE\_SVEALAND = {
    id = 1
    subsistence\_building = "building\_subsistence\_pastures"
    provinces = { "x0974E5" "x216569" "x24A2F1" "x298E7B" "x317138" "x36F523" "x3844C0" "x3E2C22" "x404643" "x41C729" "x432E07" "x45B6EF" "x4628A5" "x4836F2" "x4B02EB" "x4C9918" "x4FA424" "x604060" "x62D0D4" "x656512" "x6CF949" "x6E95C2" "x6F40EC" "x823263" "x8AC21D" "x90845E" "x93C3BC" "x93C76C" "x9686A5" "x9BBBE3" "xA001A0" "xA08021" "xA6C31B" "xA82FF7" "xA86C50" "xA9078A" "xB3F1FB" "xB90566" "xB9391F" "xBC0288" "xC0C0E0" "xC480A5" "xC8AEAF" "xCBFD28" "xCF16B1" "xD155CE" "xD702F7" "xD96FB9" "xE6C5FC" "xE7A6D6" "xE9B084" "xEA6A0F" "xEB5D5F" "xEFA14D" "xF08323" "xF48646" "xF8E400" "xFCCAFA" }

## Base characteristics\[[edit](/index.php?title=State_modding&veaction=edit&section=2 "Edit section: Base characteristics") | [edit source](/index.php?title=State_modding&action=edit&section=2 "Edit section: Base characteristics")\]

Each state region is defined with its unique script name and unique ID number. The script name also acts as a [localization](/Localization "Localization") key.

All state regions must contain one or more 'provinces' tiles from the `provinces.png` map image. Provinces are defined by the six-digit [hex color](http://en.wikipedia.org/wiki/Web_colors#Hex_triplet "wikipedia:Web colors") in that image, each prefixed by the letter `x` and optionally enclosed in double quotes.

Naval state regions (which define [sea nodes](/Naval_warfare#Sea_nodes "Naval warfare")) contain precisely these characteristics and no more.

Example naval state region:

STATE\_BALTIC\_SEA = {
    id = 3000
    provinces = { "x08FAFA" }
}

## Additional characteristics\[[edit](/index.php?title=State_modding&veaction=edit&section=3 "Edit section: Additional characteristics") | [edit source](/index.php?title=State_modding&action=edit&section=3 "Edit section: Additional characteristics")\]

Land regions have a number of other characteristics.

### Impassable and prime land\[[edit](/index.php?title=State_modding&veaction=edit&section=4 "Edit section: Impassable and prime land") | [edit source](/index.php?title=State_modding&action=edit&section=4 "Edit section: Impassable and prime land")\]

States can have a list of impassable and prime land provinces. Both are relevant for split states as they affect the proportion of resources allocated to each state. Impassable provinces are not counted for the split state proportion and additionally block military fronts from forming. Prime land provinces give five times the weight for the split state proportion[\[1\]](#cite_note-1).

Both lists should only include provinces defined for the state region and should not include provinces from each other.

Example:

    provinces = { "x029E85" "x04BB3B" "x1C7417" "x2A3D46" "x42973E" "x4408AB" "x445D59" "x477680" "x4DD36E" "x56FE77" "x60FDC2" "x638173" "x6D4CDF" "x706E00" "x71D428" "x76E306" "x7FFBF0" "x8A69A7" "x939612" "x9910E9" "xA5A916" "xA67A6E" "xA6D36E" "xA91194" "xAD54BC" "xB7B05B" "xBC374E" "xC29C28" "xCF4105" "xD735DB" "xE02CB6" "xE3C4F2" "xF37396" "xF8375D" "xF9BDCB" "xFCFD83" "xFF8539" "xFFE074" }
    impassable = { "xA5A916" "xBC374E" "x04BB3B" "x9910E9" "xCF4105" "x477680" "x56FE77" }
    prime\_land = { "xE02CB6" "x60FDC2" "x42973E" }

### Hubs\[[edit](/index.php?title=State_modding&veaction=edit&section=5 "Edit section: Hubs") | [edit source](/index.php?title=State_modding&action=edit&section=5 "Edit section: Hubs")\]

Hubs are defined provinces that represent a city within the state region. Visually, each type of hub appears and grows based on the number of buildings related to its type in the state region. Most hubs have no game mechanic interaction aside from updating the road/rail network by their presence or absence; port hubs define the location of [![State status treaty port.png](/images/thumb/7/70/State_status_treaty_port.png/24px-State_status_treaty_port.png)](/Treaty_port "Treaty port") treaty ports.

Hub

Buildings

City

Everything not included in other hubs

Farm

All agriculture and plantations

Mine

All mines and oil rigs

Port

-   Shipyards and Military Shipyards
-   Fishing and Whaling Industries
-   Ports and Naval Bases

Wood

Logging Camps

Hubs can overlap, such that the same province is two or more hubs, and not every state region has every type of hub, notably inland states have no port hub. Each hub is defined by listing the province which is used for that hub.

### State traits\[[edit](/index.php?title=State_modding&veaction=edit&section=6 "Edit section: State traits") | [edit source](/index.php?title=State_modding&action=edit&section=6 "Edit section: State traits")\]

Some state regions have a defined [state trait](/State_trait "State trait"). These are listed in a block `traits` with each trait listed in quotes with its script name. State traits are defined in common/state\_traits.

A state trait is defined with a unique script name – which also acts as a localization key, an icon, and typically a modifier. State traits can also have a disabling technology, which suppresses its modifier or a technology required for colonization, which prevents colonization of state regions with the trait until that technology is researched.

Example state trait:

state\_trait\_severe\_malaria = {
    icon = "gfx/interface/icons/state\_trait\_icons/severe\_malaria.dds"
	
	required\_techs\_for\_colonization = { "quinine" }
	disabling\_technologies = { "malaria\_prevention" }
	
	modifier = {
		state\_non\_homeland\_colony\_growth\_speed\_mult = -0.95
		state\_non\_homeland\_mortality\_mult = 0.25
	}
}

Effects can also add or remove state traits to state regions during gameplay.

### Resources\[[edit](/index.php?title=State_modding&veaction=edit&section=7 "Edit section: Resources") | [edit source](/index.php?title=State_modding&action=edit&section=7 "Edit section: Resources")\]

Resources in a state region come in a few types: arable land and resources, capped resources, and individual resources. In all cases, the resources are defined as [building groups](/Building_modding "Building modding") and many of the resource characteristics are defined by the building group's characteristics.

#### Arable land\[[edit](/index.php?title=State_modding&veaction=edit&section=8 "Edit section: Arable land") | [edit source](/index.php?title=State_modding&action=edit&section=8 "Edit section: Arable land")\]

Arable land is defined simply as an integer, along with a list of building groups that use arable land in the state region.

Example:

    arable\_land = 30
    arable\_resources = { "bg\_rye\_farms" "bg\_livestock\_ranches" }

Unutilized arable land is always taken up by a subsistence building, which is defined for each state region as the specific type of building, for example `subsistence_building = "building_subsistence_pastures"`.

#### Capped resources\[[edit](/index.php?title=State_modding&veaction=edit&section=9 "Edit section: Capped resources") | [edit source](/index.php?title=State_modding&action=edit&section=9 "Edit section: Capped resources")\]

Capped resources are a block of building groups with a maximum level defined for each. These resources are always visible from the start of the game.

Example:

    capped\_resources = {
        bg\_iron\_mining = 36
        bg\_lead\_mining = 18
        bg\_logging = 23
        bg\_fishing = 11
    }

#### Individual resources\[[edit](/index.php?title=State_modding&veaction=edit&section=10 "Edit section: Individual resources") | [edit source](/index.php?title=State_modding&action=edit&section=10 "Edit section: Individual resources")\]

Individual resources are similar to capped resources, but each one is defined in its own block. Most often these are used for discoverable resources, which are not immediately visible in game, and instead are revealed periodically once the state's owner has the required technology researched. Additionally, if a building group is set as depletable, this block can define which building group replaces it when it is depleted.

Example:

    resource = {
        type = "bg\_gold\_fields"
        depleted\_type = "bg\_gold\_mining"
        undiscovered\_amount = 12
    }
    resource = {
        type = "bg\_rubber"
        discovered\_amount = 10
        undiscovered\_amount = 6
    }
    resource = {
        type = "bg\_oil\_extraction"
        undiscovered\_amount = 5
    }

### Naval exit\[[edit](/index.php?title=State_modding&veaction=edit&section=11 "Edit section: Naval exit") | [edit source](/index.php?title=State_modding&action=edit&section=11 "Edit section: Naval exit")\]

Coastal state regions should have a `naval_exit_id`, which is simply the state region ID of a sea region. This defines which sea region/sea node is adjacent to this state region, for the purposes of shipping lanes and naval invasions.

## Strategic region\[[edit](/index.php?title=State_modding&veaction=edit&section=12 "Edit section: Strategic region") | [edit source](/index.php?title=State_modding&action=edit&section=12 "Edit section: Strategic region")\]

[Strategic regions](/Strategic_region "Strategic region") are collections of state regions. They provide the basis for both diplomatic interests and military HQs. Strategic regions are defined in common/strategic\_regions.

Each strategic region is defined as a unique script name, which also acts as a localization key, a capital province, percentage RGB map color, list of states, and optionally a graphical culture.

Example:

strategic\_region\_name = {
	capital\_province = province\_id	# The province ID for the capital of the state, determines where the UI panel for the interest markers present appears
	map\_color = { R% G% B% }		# The percentage of R G B colour for this region for the diplomatic map mode
	states = { state\_key\_list }		# The states included in this strategic region specified by key
	graphical\_culture = "script\_name" # Defines which style is used for on-map building models, "European/Western" is the "default" style and left undefined
}

Each state can be included in only one strategic region. Naval state regions are also included in strategic regions, one per state. These naval strategic regions do not have a capital province, map color, or graphical culture.

Example naval strategic region:

region\_baltic\_sea = {
	states = { STATE\_BALTIC\_SEA }
}

## State history\[[edit](/index.php?title=State_modding&veaction=edit&section=13 "Edit section: State history") | [edit source](/index.php?title=State_modding&action=edit&section=13 "Edit section: State history")\]

*See also: [New state modding](/New_state_modding "New state modding")*

Starting state ownership is defined in common/history/states. Unmodified Victoria 3 puts all state history in the file `00_states.txt`, but it can be split into separate files for mods.

State history files use a block `STATES` which includes a number of state regions.

STATES = {
	s:STATE\_LOWER\_EGYPT = {
		create\_state = {
			country = c:EGY
			owned\_provinces = { x409060 x2050A0 x7ABE4B x50D0E0 x5011E0 x48E2A5 x6F13AD xD050E0 xF47AAA xA0D020 xC09060 xC37990 }
		}
		
		add\_homeland = cu:misri
	}
    s:STATE\_IONIAN\_ISLANDS = {
		create\_state = {
			country = c:ION
			owned\_provinces = { x4B79CA x405060 }
		}	
		# Homelands and claims are defined on the state region, not for individual states
		add\_homeland = cu:greek
		add\_claim = c:GRE
	}
    s:STATE\_BALUCHISTAN = {
		create\_state = {
			country = c:OMA
			state\_type = treaty\_port #treaty port states should be defined from only the port hub province of a state region
			owned\_provinces = { "xB7B2BD" }
		}
		create\_state = {
			country = c:KAL
			owned\_provinces = { "x0279A0" "x0BAF8C" "x1161D9" "x1D0224" "x2B7441" "x35754E" "x3C9B5F" "x43F4B8" "x4529BD" "x4B2EAD" "x4DC3FF" "x4F800F" "x556C63" "x56CF62" "x5CBA3C" "x61D696" "x626396" "x62BEAA"  "x6D6D6B" "x782112" "x7D60E7" "x8DC922" "x954C12" "x97C017" "xA3655B" "xB2AAA7" "xBAE3D2" "xBB836E" "xC6D9E8" "xCD77FD" "xD4EC50" "xD6DD8A" "xDEE571" "xDF30A0  " "xE7A309" "xE92A58" "xEC696F" "xF78D0D"  "x1EF53E" }
		}
		create\_state = {
			country = c:MAK
			owned\_provinces = { "x978421" "x4E09C5" "xF9577D" "x45F2DD" "x113E0B" "x7FE584" "xC070E0" "xC6E602" "xB0F79E" "x407060" "x951063" "x8ED831" "x2E7961" "xE87BBF" "x968562" "x675BCE" "x2FF46D" }
		}
		create\_state = {
			country = c:KAN
			owned\_provinces = { "xE712E1" "xF1414C" "x17D8AB" "x3EFD1E" "x109CC0" "x4070E0" "x9EED5C" "xA55509" "xD575B0" }
		}
		
		add\_homeland = cu:baluchi
		add\_homeland = cu:pashtun
	}
}

State regions are called with `s:<state region name>` and can be given homelands and country claims. Each state region must have at least one state created from it.

Each created state is defined from a state region with the effect `create_state`, which requires the owning country and a list of provinces. The list of provinces can be part or all of the state region. The state can also be defined with a `state_type`, states are incorporated by default, but can be defined as `unincorporated` or as a `treaty_port`. Note that a country's capital state is automatically and immediately incorporated, regardless of the state history.

Countries that start the game with [![Colonial affairs](/images/thumb/1/1d/Institution_colonization.png/24px-Institution_colonization.png)](/Institutions#Colonial_affairs "Institutions") Colonial Affairs also start with colonies in every owned state region that also contains a neighboring decentralized nation. These initial colonies ignore colonial claims.

The states defined in common/history/states are referenced in common/history/buildings and common/history/pops, so take care to update all relevant files when changing the starting setup.
