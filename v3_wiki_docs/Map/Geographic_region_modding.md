# Geographic region modding

From Victoria 3 Wiki

[Jump to navigation](#mw-head) [Jump to search](#searchInput)

 

This article has been verified for the current [version](/Victoria_3_Wiki:Versioning "Victoria 3 Wiki:Versioning") (1.12) of the game.

**Geographic regions**, also called *Georegions*, are static lists of [state regions and/or strategic regions](/State_modding "State modding") defined in script. These can be iterated in script, helping reduce the complexity of iterations and are better supported by the game engine for performance. When used in [localization](/Localization "Localization"), hovering over the geographic region name highlights all included state regions on the game map. Geographic regions can be used to group state regions separately from strategic regions and can also include more abstract regions such as climate zones or coastlines.

***The usage of georegion iterators is highly recommended by the game developers for performance reasons.***

## Definition\[[edit](/index.php?title=Geographic_region_modding&veaction=edit&section=1 "Edit section: Definition") | [edit source](/index.php?title=Geographic_region_modding&action=edit&section=1 "Edit section: Definition")\]

Geographic regions are defined in the common/geographic\_regions folder.

*All geographic region files must be in UTF-8 BOM encoding.*

A geographic region definition consists of the following elements:

-   Geographic region key, used to call the geographic region
-   Short key, for use in iterators
-   List of included strategic regions
-   List of included state regions

A geographic region can include any number of strategic or state regions, or exclusively state or strategic regions.

geographic\_region\_key = {
	# All state/strategic regions are added together to form a geographic region

	# the key to access this in script lists i.e <any/..>\_<state/...>\_in\_europe
	short\_key = "europe"

	# The Strategic Regions this geographic region encompasses
	strategic\_regions = { sr:<key> sr:<key> sr:<key> }

	# The State Regions this geographic region encompasses
	state\_regions = { <STATE\_REGION> <STATE\_REGION> }
}

## Usage\[[edit](/index.php?title=Geographic_region_modding&veaction=edit&section=2 "Edit section: Usage") | [edit source](/index.php?title=Geographic_region_modding&action=edit&section=2 "Edit section: Usage")\]

The [trigger](/Trigger "Trigger") `is_in_geographic_region` checks if the scoped object is included in a specific geographic region. This can be used in the country, state, state\_region, or strategic\_region scopes.

any\_scope\_state = {
    is\_in\_geographic\_region = geographic\_region\_south\_america
    is\_incorporated = yes
    count >= 10
}

When used in a country scope or country iterator, this trigger checks only for the *capital state* of that country.

### Iterators\[[edit](/index.php?title=Geographic_region_modding&veaction=edit&section=3 "Edit section: Iterators") | [edit source](/index.php?title=Geographic_region_modding&action=edit&section=3 "Edit section: Iterators")\]

A geographic region can be used to iterate any included regions in a more performance friendly manner. *This method is highly recommended by the game developers as \_country and \_state iterators are inherently expensive.*

The supported iterators are as follows:

-   `{any|every|ordered|random}_country_in_<geographic_region_short_key>`
-   `{any|every|ordered|random}_province_in_<geographic_region_short_key>`
-   `{any|every|ordered|random}_state_in_<geographic_region_short_key>`
-   `{any|every|ordered|random}_state_region_in_<geographic_region_short_key>`
-   `{any|every|ordered|random}_strategic_region_in_<geographic_region_short_key>`

Example, from `je_springtime_of_the_peoples`:

	possible = {
		any\_country\_in\_europe = {
			has\_technology\_researched = egalitarianism
        }
		custom\_tooltip = {
			text = peoples\_springtime\_underway\_tt
			has\_global\_variable = peoples\_springtime\_happening
		}
	}

Example, from `je_sale_of_alaska`:

		custom\_tooltip = {
			text = friendly\_nation\_with\_interest\_in\_alaska\_tt
			any\_country\_in\_north\_america = {
				NOT = {
					is\_subject = yes
				}
				relations:root >= 0
				country\_rank >= rank\_value:great\_power
				any\_scope\_state = {
					region = sr:region\_pacific\_coast
					is\_incorporated = yes
				}
			}
		}

### Production methods\[[edit](/index.php?title=Geographic_region_modding&veaction=edit&section=4 "Edit section: Production methods") | [edit source](/index.php?title=Geographic_region_modding&action=edit&section=4 "Edit section: Production methods")\]

Geographic regions can be used to unlock [production methods](/Production_methods_modding "Production methods modding") by adding an `unlocking_geographic_regions` to the production method and listing any geographic regions by full key. For example:

	unlocking\_geographic\_regions = {
		geographic\_region\_wet\_process\_coffee\_region
	}

## Localization\[[edit](/index.php?title=Geographic_region_modding&veaction=edit&section=5 "Edit section: Localization") | [edit source](/index.php?title=Geographic_region_modding&action=edit&section=5 "Edit section: Localization")\]

Geographic regions are localized as follows:

-   `<geographic_region_key>` for the name of the geographic region
-   `<geographic_region_key>_desc` for any fluff/lore description of your geographic region

For example:

 geographic\_region\_ring\_of\_fire: "Ring of Fire"
 geographic\_region\_ring\_of\_fire\_desc: "A chain of seismically active sites and volcanoes around the edge of the Pacific Ocean."

Geographic regions can be called by script name in localization using the `GetGeographicRegion()` function. For example:

 je\_eastern\_frontier\_tt\_1: "\[GetGeographicRegion('geographic\_region\_greater\_khorasan').GetName\] is owned by \[SCOPE.GetRootScope.GetCountry.GetName\] or its subjects."
 je\_eastern\_frontier\_tt\_2: "\[GetGeographicRegion('geographic\_region\_chorasmia').GetName\] is owned by \[SCOPE.GetRootScope.GetCountry.GetName\] or its subjects."
 je\_eastern\_frontier\_tt\_3: "\[GetGeographicRegion('geographic\_region\_transoxiana').GetName\] is owned by \[SCOPE.GetRootScope.GetCountry.GetName\] or its subjects."

*When hovered over in the UI, the geographic region will be highlighted on the game map.*
