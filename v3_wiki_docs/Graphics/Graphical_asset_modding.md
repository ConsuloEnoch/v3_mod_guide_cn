## 2-D Assets\[[edit](/index.php?title=Graphical_asset_modding&veaction=edit&section=1 "Edit section: 2-D Assets") | [edit source](/index.php?title=Graphical_asset_modding&action=edit&section=1 "Edit section: 2-D Assets")\]

Victoria 3 primarily uses the *DirectDraw Surface* (.dds) file format for storing texture assets. These are scaled as needed by the UI. While the game can accept any resolution, compressed must have resolutions dividable by 4, or the UI will show buggy scaling behavior and will print an error to the log.

### Exporting images via Paint.NET\[[edit](/index.php?title=Graphical_asset_modding&veaction=edit&section=2 "Edit section: Exporting images via Paint.NET") | [edit source](/index.php?title=Graphical_asset_modding&action=edit&section=2 "Edit section: Exporting images via Paint.NET")\]

Paint.NET is a flexible and beginner-friendly tool for .dds editing. This can be found at [https://www.getpaint.net/](https://www.getpaint.net/).

#### Saving a compressed image:\[[edit](/index.php?title=Graphical_asset_modding&veaction=edit&section=3 "Edit section: Saving a compressed image:") | [edit source](/index.php?title=Graphical_asset_modding&action=edit&section=3 "Edit section: Saving a compressed image:")\]

In the save configuration:

1.  Select **BC7 (sRGB, DX 11+)**
2.  Check "**Generate Mip Maps**"
    1.  The dropdown below this checkbox determines the interpolation algorithm used to figure out how the image will look when resized. The default should be **Bicubic**, and this is perfectly workable for virtually all cases. You shouldn't change this unless you know what you're doing. It is important to select a good option and avoid other ones because this will determine how your image looks when downsized, as is often the case for things such as [Ideology](/Ideology "Ideology") icons. Picking a poor option will often lead to your texture looking bad in some UI panels, such as looking very pixelated or "crunchy" when using Nearest Neighbor.

*Remember to keep your resolution divisible by 4!*

[![](/images/thumb/6/63/Paint_dot_net_export_settings.png/450px-Paint_dot_net_export_settings.png)](/File:Paint_dot_net_export_settings.png)

[](/File:Paint_dot_net_export_settings.png "Enlarge")

Recommended export options for Paint.NET .dds export

#### Saving an uncompressed image:\[[edit](/index.php?title=Graphical_asset_modding&veaction=edit&section=4 "Edit section: Saving an uncompressed image:") | [edit source](/index.php?title=Graphical_asset_modding&action=edit&section=4 "Edit section: Saving an uncompressed image:")\]

In the save configuration:

1.  Select **B8G8R8A8 (Linear, A8R8G8B8)**
2.  Check "**Generate Mip Maps"**
    1.  See the note about the interpolation algorithm dropdown above in the compressed image instructions. The default is **Bicubic** and this should be the setting used to make sure your texture looks good unless you know what you're doing.

### Exporting images via GIMP\[[edit](/index.php?title=Graphical_asset_modding&veaction=edit&section=5 "Edit section: Exporting images via GIMP") | [edit source](/index.php?title=Graphical_asset_modding&action=edit&section=5 "Edit section: Exporting images via GIMP")\]

GIMP is a powerful tool similar to Photoshop in scope and features. This can be found at [https://www.gimp.org/](https://www.gimp.org/).

In the export settings:

1.  Set your compression to **BC3 / DXT5**
2.  **Generate mipmaps** for everything *except* event pictures
3.  It is recommended to use **Kaiser** filter for generating mipmaps, as default can look worse
