# Character modding

From Victoria 3 Wiki

[Jump to navigation](#mw-head) [Jump to search](#searchInput)

 

Please help with verifying or updating older sections of this article.  
At least some were last verified for [version](/Victoria_3_Wiki:Versioning "Victoria 3 Wiki:Versioning") 1.11.

[Characters](/Character "Character") are defined either with character templates in /common/character\_templates/ or the `create_character` [effect](/Effect "Effect"). Starting characters are found in /common/history/characters/, and many characters are defined in events or other effects as well.

Character templates can be used with the `create_character` effect to generate characters, or they can appear semi-randomly if a usage block is defined.

## Character templates\[[edit](/index.php?title=Character_modding&veaction=edit&section=1 "Edit section: Character templates") | [edit source](/index.php?title=Character_modding&action=edit&section=1 "Edit section: Character templates")\]

Character templates are defined in /common/character\_templates/, as an example:

usa\_rockefeller\_character\_template = {
    first\_name = John
    last\_name = Rockefeller
    historical = yes
    dna = dna\_john\_d\_rockefeller
    culture = cu:yankee
    female = no
    religion = rel:protestant
    ideology = ideology\_moderate
    interest\_group = ig\_industrialists
    birth\_date = 1839.6.8
    traits = {
        ambitious
        persistent
        basic\_entrepreneur
    }
    executive\_usage = {
      country\_trigger = {
        exists = c:USA
        this = c:USA
      }
      company\_trigger = {
        is\_company\_type = company\_type:company\_standard\_oil
      }
      earliest\_usage\_date = 1875.1.1
      latest\_usage\_date = 1915.1.1
      chance = 100
    }
    commander\_usage = {
      country\_trigger = {
        exists = c:USA
        this = c:USA
      }
      role = general
      earliest\_usage\_date = 1836.1.1
      latest\_usage\_date = 1860.1.1
      chance = 75
    }
}

Character templates can include one or more **usage** blocks, which allow the template to be used as a randomly generated character, rather than generating the character by effect. Once a template has been generated by a usage block or `create_character`, it cannot be generated by a usage block again.

### Character names\[[edit](/index.php?title=Character_modding&veaction=edit&section=2 "Edit section: Character names") | [edit source](/index.php?title=Character_modding&action=edit&section=2 "Edit section: Character names")\]

*See also: [Localization](/Localization "Localization")*

**NOTE:** All text presented to the player ***must*** be done through localization keys. Unlocalized character names default to a random name from the character's culture.

Base game character names are defined in /Victoria 3/game/localization/<language>/names\_l\_<language>.yml; new character names can be defined in any localization file. Character names can be assigned to [cultures](/Culture_modding "Culture modding"), or used only for specific character templates.

## Create character effect\[[edit](/index.php?title=Character_modding&veaction=edit&section=3 "Edit section: Create character effect") | [edit source](/index.php?title=Character_modding&action=edit&section=3 "Edit section: Create character effect")\]

The [effect](/Effect "Effect") `create_character` can use a defined character template, define a character using the same parameters as character templates, or use a template then modify it with additional parameters.

## Character history\[[edit](/index.php?title=Character_modding&veaction=edit&section=4 "Edit section: Character history") | [edit source](/index.php?title=Character_modding&action=edit&section=4 "Edit section: Character history")\]

Starting characters can be found at /common/history/characters/. They can be created from templates or direct definitions in `create_character`

## Character traits\[[edit](/index.php?title=Character_modding&veaction=edit&section=5 "Edit section: Character traits") | [edit source](/index.php?title=Character_modding&action=edit&section=5 "Edit section: Character traits")\]

Character traits are defined in /common/character\_traits/

When adding modded traits instead of modifying existing vanilla traits, create a new file.

notorious = {
  type = condition                            # Can be one of personality, skill, or condition. Each category is limited by defines. Random traits can be applied based on a particular type.
  texture = "gfx/interface/icons/character\_trait\_icons/direct.dds"  # The trait's texture asset

  character\_modifier = {                      # Applies to the Character regardless of role
    character\_popularity\_add = 25
  }

  command\_modifier = {                        # Applies to the Character, their Military Formation, and any Combat Units under the Character's command, assuming the unit is fully Mobilized (or does not need to Mobilize)
    unit\_kill\_rate\_mult = 0.1
  }
  
  country\_modifier = {                        # Applies to the Character's Country if they are the Ruler of it
    state\_turmoil\_mult = 0.1
  }
  
  agitator\_modifier = {
    political\_movement\_radicalism\_add = 0.15  # Applies to the Character's Political Movement
  }
    
  interest\_group\_modifier = {                 # Applies to the Character's Interest Group if they are the Leader of it
    interest\_group\_pol\_str\_mult = -0.05
    interest\_group\_pop\_attraction\_mult = 0.1
  }

  executive\_modifier = {                      # Applies to the Character's Company if they are the Executive of it
    building\_cash\_reserves\_mult = -0.1
  }

  possible = {                                # Used to determine if this trait is a valid random choice
    popularity < 0                            # Does NOT impact the validity of the trait once it's acquired
  }

  weight = {                                  # Script value to determine how likely it is the character will randomly get this trait, compared to other traits in its category. Default 1
    value = popularity
    multiply = -1
  }

  replace = {                                 # When the character gains this trait, any traits they have in the following list are removed
    famous
    wicked
  }

  value = 2                                   # How much this trait is "worth" in experience levels traits. Default 1
                                              # Used to determine whether the character is owed more traits, and which trait category is overrepresented
}

### Trait localization\[[edit](/index.php?title=Character_modding&veaction=edit&section=6 "Edit section: Trait localization") | [edit source](/index.php?title=Character_modding&action=edit&section=6 "Edit section: Trait localization")\]

*See also: [Localization](/Localization "Localization")*

Traits generate two localization keys: `<trait_name>` and `<trait_name>_desc`, for the name and flavor description.
