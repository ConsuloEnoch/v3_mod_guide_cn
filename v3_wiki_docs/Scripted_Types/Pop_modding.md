# Pop modding

From Victoria 3 Wiki

[Jump to navigation](#mw-head) [Jump to search](#searchInput)

 

Please help with verifying or updating older sections of this article.  
At least some were last verified for [version](/Victoria_3_Wiki:Versioning "Victoria 3 Wiki:Versioning") 1.9.

[Pops](/Pops "Pops") have many attributes, but they are most fundamentally defined by their [profession](/Profession "Profession").

## Profession definition\[[edit](/index.php?title=Pop_modding&veaction=edit&section=1 "Edit section: Profession definition") | [edit source](/index.php?title=Pop_modding&action=edit&section=1 "Edit section: Profession definition")\]

Professions are defined in /Victoria 3/game/common/pop\_types. Each profession is defined with a script name and a number of characteristics

example = {	# profession name
	texture = "gfx/interface/icons/pops\_icons/example.dds"		# profession icon
	color = { 12 251 123 }				# profession color; unmodified professions all use decimal hsv
	strata = middle					# strata that profession belongs to; poor (lower), middle, or rich (upper)
	start\_quality\_of\_life = 10			# basic quality of life/standard of living
	wage\_weight = 3					# multiplier of the pop's wage from building's base wage
	paid\_private\_wage = yes/no			# whether this pop type receives wages in a non government funded building (default no)
	education\_access = 0.25				# bonus amount of education access
	consumption\_mult = 1				# optional goods consumption multiplier (default = 1)
	dependent\_wage = 0.5				# wage for dependents per year
	unemployment = yes				# can pop be unemployed
	unemployment\_wealth = 5				# unemployed pops whose wealth drops to or below this level switches '''to''' this profession
	can\_always\_hire = yes				# profession does not require qualifications
	subsistence\_income = yes			# profession benefits from subsistence income
	ignores\_employment\_proportionality = yes	# buildings can hire this profession even if unable to hire other professions
	is\_slave = yes					# profession is enslaved
    military = yes					# profession is military
    
	# 50% - 100% politically engaged
	political\_engagement\_base = 0.5				# basic political engagement
	political\_engagement\_literacy\_factor = 1.0		# literacy to political engagement, scaled by literacy
	
	political\_engagement\_mult = { value = 1	}		# scripted value to escalate dynamic political engagement value
	
	qualifications\_growth\_desc = "ENGINEERS\_QUALIFICATIONS\_DESC"		# Qualifications growth desc localization
	qualifications = {}					# Qualifications scripted values list

	portrait\_age = { value = 30 }				# Age for portrait
	portrait\_pose = { value = 0 }				# Pose for portrait
	portrait\_is\_female = { always = yes }			# Is portrait female or male
}

There are two [defines](/Defines "Defines") that refer to professions directly: `DEFAULT_POP_TYPE` and `SLAVE_POP_TYPE`, be sure to update these if replacing unmodified professions.

## Profession modifiers\[[edit](/index.php?title=Pop_modding&veaction=edit&section=2 "Edit section: Profession modifiers") | [edit source](/index.php?title=Pop_modding&action=edit&section=2 "Edit section: Profession modifiers")\]

*See also: [Modifier types § Object-based modifiers](/Modifier_types#Object-based_modifiers "Modifier types")*

There are a number of [modifier types](/Modifier_types "Modifier types") related to each profession. New professions require these new modifiers be scripted as well.

Common modifiers

-   building\_employment\_\[profession\]\_add
-   building\_employment\_\[profession\]\_mult
-   country\_\[profession\]\_pol\_str\_mult
-   country\_\[profession\]\_voting\_power\_add
-   state\_\[profession\]\_mortality\_mult

Less common modifiers

-   building\_group\_\[group\]\_\[profession\]\_mortality\_mult
-   building\_group\_\[group\]\_\[profession\]\_standard\_of\_living\_add
-   building\_\[profession\]\_shares\_add
-   state\_\[profession\]\_investment\_pool\_contribution\_add
-   state\_\[profession\]\_investment\_pool\_contribution\_mult
