# Power bloc modding

From Victoria 3 Wiki

[Jump to navigation](#mw-head) [Jump to search](#searchInput)

 

Please help with verifying or updating older sections of this article.

*See also: [Power bloc](/Power_bloc "Power bloc")*

[Power blocs](/Power_bloc "Power bloc") represent international organizations, associations, and empires. Each power bloc has a *central identity* and a number of *principles*. Modding power blocs and principles typically involves modifying several related concepts.

## DLC-locked features\[[edit](/index.php?title=Power_bloc_modding&veaction=edit&section=1 "Edit section: DLC-locked features") | [edit source](/index.php?title=Power_bloc_modding&action=edit&section=1 "Edit section: DLC-locked features")\]

Power blocs have a number of DLC-locked features. These include most unmodified identities and principles, as well as the ability to add more than one principle to a power bloc. Mods may not unlock DLC-locked content, so any mod features that modify or replicate DLC-locked power bloc content **must** include the trigger `has_dlc_feature = power_bloc_features` to enable those features.

Entirely new identities, principles, or other new content related to power blocs do not require this trigger unless they replicate or depend on an existing DLC-locked feature.

[![Power bloc trade league.png](/images/thumb/c/c0/Power_bloc_trade_league.png/24px-Power_bloc_trade_league.png)](/Trade_League "Trade League") Trade League and its primary principles [![External Trade](/images/thumb/f/fd/Principle_external_trade.png/30px-Principle_external_trade.png)](/Power_bloc#External_Trade "External Trade") External Trade and [![Internal Trade](/images/thumb/d/d0/Principle_internal_trade.png/30px-Principle_internal_trade.png)](/Power_bloc#Internal_Trade "Internal Trade") Internal Trade are *not* DLC-locked, and so can be modified freely.

## Central identity definition\[[edit](/index.php?title=Power_bloc_modding&veaction=edit&section=2 "Edit section: Central identity definition") | [edit source](/index.php?title=Power_bloc_modding&action=edit&section=2 "Edit section: Central identity definition")\]

Power bloc identities define the type of power bloc, and include base modifiers and values such as cohesion.

Central identities are defined in /Victoria 3/game/common/power\_bloc\_identities. The basic definition is a script name, icon, background, and a number of triggers, modifiers, and script values. For example:

identity\_trade\_league = {
	power\_bloc\_modifier = {
		power\_bloc\_customs\_union\_bool = yes
		power\_bloc\_mandate\_progress\_per\_great\_power\_member\_add = 10
		power\_bloc\_mandate\_progress\_per\_major\_power\_member\_add = 5
		power\_bloc\_mandate\_progress\_per\_minor\_power\_member\_add = 2
		power\_bloc\_mandate\_progress\_per\_unrecognized\_major\_power\_member\_add = 2
		power\_bloc\_mandate\_progress\_per\_unrecognized\_regional\_power\_member\_add = 1
		power\_bloc\_cohesion\_per\_member\_add = -1
		power\_bloc\_invite\_acceptance\_great\_power\_add = -15
	}

	leader\_modifier = {
		country\_trade\_route\_quantity\_mult = 0.1
	}
	
	non\_leader\_modifier = {
		country\_convoy\_contribution\_to\_market\_owner\_add = 0.2
	}

	member\_modifier = {
	}

	can\_leave = {
		OR = {
			is\_power\_bloc\_leader = yes
			power\_bloc = {
				leverage\_advantage = {
					target = root
					value <= 30
				}
			}
		}
	}
	
	possible = {
		# NOT = { has\_law = law\_type:law\_isolationism }
	}

	icon = "gfx/interface/icons/central\_identity\_pillars\_icons/trade\_league.dds"
	background = "gfx/interface/power\_blocs/backgrounds/pb\_background\_generic.dds"

	mandate\_progress = power\_bloc\_mandate\_progress\_by\_rank
	
	on\_created = { relations\_hit\_with\_power\_bloc\_leaders = yes }
	
	cohesion = {
		\[script value\]
		add = {
			add = 0.15
			multiply = define:NPowerBlocs|COHESION\_TARGET\_MAX
			desc = POWER\_BLOC\_COHESION\_BASE
		}
	}
	
	ai\_weight = {
		\[script value\]
	}
}

Script names can be anything and the script name also generates [localization](/Localization "Localization") keys: `[script name]` and `[script_name]_desc`. The identity is used for triggers, so a clear, but unique name is good to use.

The follow characteristics can be scripted for each identity:

Characteristic

Description

icon

Icon that represents the identity

background

Background image for the power bloc screen when using this identity

visible

Trigger block that must return true for this identity to be visible

possible

Trigger block that must return true for this identity to be selectable

can\_leave

Trigger block that must return true for a country to voluntarily leave the power bloc

on\_created

Effect block that occurs when this power bloc is first formed

power\_bloc\_modifier

Modifiers that affect the power bloc directly

leader\_modifier

Modifiers that affect the power bloc leader only

non\_leader\_modifier

Modifiers that affect only the non-leader members of the power bloc

member\_modifier

Modifiers that affect all members of the power bloc

mandate\_progress

Script value that determines how quickly mandates are gained

cohesion

Script value that determines the cohesion target of the bloc

ai\_weight

Script value that determines which identity an AI values most

## Principle group definition\[[edit](/index.php?title=Power_bloc_modding&veaction=edit&section=3 "Edit section: Principle group definition") | [edit source](/index.php?title=Power_bloc_modding&action=edit&section=3 "Edit section: Principle group definition")\]

Power bloc principles are grouped such that each group represents a principle with each level defined within. Principle groups are defined in /Victoria 3/game/common/power\_bloc\_principle\_groups. Each principle group requires a script name and a `levels` block which lists one or more principles. Additionally, they can include the following characteristics:

Characteristic

Description

unlocking\_identity

Identity required to select this principle group

blocking\_identity

Identity which cannot select this principle group

primary\_for\_identity

This principle group is a primary principle for the given identity

Like identities, the script name can be anything and generates the localization keys `[script_name]` and `[script_name]_desc`

Unmodified Victoria 3 always and only uses three levels for each group, but this is not a strict requirement. Each entry is consider a level higher than the previous, which affects the number of mandates required to change to that principle.

Example principle group:

principle\_group\_internal\_trade = {
	primary\_for\_identity = identity\_trade\_league
	unlocking\_identity = identity\_trade\_league
	
	levels = {
		principle\_internal\_trade\_1
		principle\_internal\_trade\_2
		principle\_internal\_trade\_3
	}
}

## Principle definition\[[edit](/index.php?title=Power_bloc_modding&veaction=edit&section=4 "Edit section: Principle definition") | [edit source](/index.php?title=Power_bloc_modding&action=edit&section=4 "Edit section: Principle definition")\]

Principles are defined in /Victoria 3/game/common/power\_bloc\_principles. Each principle has certain required elements and a number of optional elements. A basic definition requires the following: a script name, an icon, a background, and an ai\_weight trigger block.

principle\_internal\_trade\_1 = {
	icon = "gfx/interface/icons/principles\_icons/internal\_trade.dds"
	background = "gfx/interface/icons/principles\_icons/principle\_tier\_1.dds"
	
	member\_modifier = {
		# Members get a bonus to Company throughput
		country\_company\_throughput\_bonus\_add = 0.1
		# More convoy going to the market owner, effect scaling upwards with principle levels
		country\_convoy\_contribution\_to\_market\_owner\_add = 0.2
	}
	
	ai\_weight = {
		value = 200 # Good for trade leagues to have
			
		if = {
			limit = { 
				OR = {
					has\_law = law\_type:law\_mercantilism 
					has\_law = law\_type:law\_command\_economy
				}
			}
			add = 100
		}	

		if = {
			limit = { 
				power\_bloc ?= { has\_principle\_group = principle\_group:principle\_group\_external\_trade }
			}
			multiply = 0.5
		}
	}	
}

Principles inherit the localization of their principle group, but still generate a new desc `[script_name]_desc`. In unmodified Victoria 3, the principle descriptions are set to reuse the principle group description, but they can have their own distinct description localization if desired.

Principles have the following characteristics:

Element

Description

icon

Icon that represents the principle

background

Background image for the principle level

visible

Trigger block that must return true for this principle to be visible

possible

Trigger block that must return true for this principle to be selectable

power\_bloc\_modifier

Modifiers that affect the power bloc directly

leader\_modifier

Modifiers that affect the power bloc leader only

non\_leader\_modifier

Modifiers that affect only the non-leader members of the power bloc

member\_modifier

Modifiers that affect all members of the power bloc

ai\_weight

Script value that determines which principle an AI values most

institution

[institution](/Institution_modding "Institution modding") affected by the principle

institution\_modifier

a modifier block added to the institution by the principle

### Principle slots\[[edit](/index.php?title=Power_bloc_modding&veaction=edit&section=5 "Edit section: Principle slots") | [edit source](/index.php?title=Power_bloc_modding&action=edit&section=5 "Edit section: Principle slots")\]

Principle slots are governed by scripted rules in /Victoria 3/game/common/scripted\_rules/00\_scripted\_rules.txt. There are two rules for each slot `unlock_power_bloc_principle_slot_#` and `unlock_power_bloc_formation_principle_slot_#`. Each of these takes a trigger block to determine whether a given slot can be used. It is unclear whether additional slots can be added (note that this would require graphical modifications as well). Note that use of slots beyond the first are a DLC-locked feature, and thus require `has_dlc_feature = power_bloc_features` as a necessary trigger to enable more slots.

## Power bloc script values\[[edit](/index.php?title=Power_bloc_modding&veaction=edit&section=6 "Edit section: Power bloc script values") | [edit source](/index.php?title=Power_bloc_modding&action=edit&section=6 "Edit section: Power bloc script values")\]

The file /Victoria 3/game/common/script\_values/01\_power\_bloc\_values.txt contains a number of defined script values related to power blocs. For example, the script values for leverage and mandate gain are both defined here as well as the AI acceptance for joining a power bloc.

## Other effects\[[edit](/index.php?title=Power_bloc_modding&veaction=edit&section=7 "Edit section: Other effects") | [edit source](/index.php?title=Power_bloc_modding&action=edit&section=7 "Edit section: Other effects")\]

Power bloc identities and principles can enable effects or actions in other files by referencing the identity or principle. Production methods are one such example, with certain principles enabling alternate production methods.

## Power bloc emblems\[[edit](/index.php?title=Power_bloc_modding&veaction=edit&section=9 "Edit section: Power bloc emblems") | [edit source](/index.php?title=Power_bloc_modding&action=edit&section=9 "Edit section: Power bloc emblems")\]

*Main article: [Flag modding](/Flag_modding#Power_bloc_emblems "Flag modding")*

Power bloc emblems are scripted in the same way as flag coats of arms. The primary difference being a square width-to-height ratio (1:1) rather than rectangular one that flags have (3:2)

The base game definition is:

    template\_power\_bloc\_1 = {
        pattern = "pattern\_solid.tga"
        color1 = { 0.0 0.0 0.0 0.0 }

        # If we ever change the order of layers here, remember to also update them
        # in NGraphics::NPowerBlocCoa::PIECE\_LAYERS\_ORDER.

        colored\_emblem = {
            texture = list "power\_bloc\_shield"
            color1 = list "power\_bloc\_colors"
            color2 = list "power\_bloc\_colors"
            instance = { scale = { 0.72 0.72 } position = { 0.49 0.6 } }  # when changing this remember to update NPowerBlocCoa in 00\_defines.txt
        }

        textured\_emblem = {
            texture = list "power\_bloc\_top"
            instance = { scale = { 0.7 0.7 } position = { 0.5 0.19 } }  # when changing this remember to update NPowerBlocCoa in 00\_defines.txt
        }

        textured\_emblem = {
            texture = list "power\_bloc\_frame"
            instance = { scale = { 0.9 0.9 } position = { 0.5 0.6 } }  # when changing this remember to update NPowerBlocCoa in 00\_defines.txt
        }

        colored\_emblem = {
            texture = list "power\_bloc\_center"
            color1 = list "power\_bloc\_colors"
            instance = { scale = { 0.45 0.45 } position = { 0.49 0.54 } }  # when changing this remember to update NPowerBlocCoa in 00\_defines.txt
        }

        textured\_emblem = {
            texture = list "power\_bloc\_side"
            instance = { scale = { 0.65 0.65 } position = { 0.155 0.55 } }  # when changing this remember to update NPowerBlocCoa in 00\_defines.txt
        }

        textured\_emblem = {
            texture = list "power\_bloc\_side"
            instance = { scale = { -0.65 0.65 } position = { 0.82 0.55 } }  # when changing this remember to update NPowerBlocCoa in 00\_defines.txt
        }
    }

The lists are defined in /Victoria 3/game/common/coat\_of\_arms/template\_lists. As the comments note, these values are also referred to in the [defines](/Defines "Defines").

Power bloc *shields* (346×346px) and *centers* (220×220px) are colored emblems in the same folder as flag colored emblems, though with a file prefix of `pb_`, rather than `ce_`. Similarly, the tops (346×346px), frames (432×432px), and sides (360×360px) are textured emblems. Note the second (right) side is flipped horizontally by inverting its X scaling factor.

Players with the ![Round frame dec.png](/images/thumb/9/9c/Round_frame_dec.png/30px-Round_frame_dec.png)[![Sphere of Influence](/images/thumb/a/a5/DLC_Sphere_of_Influence.png/30px-DLC_Sphere_of_Influence.png)](/Sphere_of_Influence_\(DLC\) "Sphere of Influence") Sphere of Influence DLC enabled can customize their power bloc emblem from the available elements, while players without can only use randomized or prescripted emblems.

Prescripted power bloc emblems are created scripting the emblem as above, then assigned by giving a very high weight to that scripted emblem in the list of random power bloc emblems in /Victoria 3/game/common/coat\_of\_arms/template\_lists/coa\_templates.txt, as is done for the base game starting power blocs.

## Power bloc names\[[edit](/index.php?title=Power_bloc_modding&veaction=edit&section=10 "Edit section: Power bloc names") | [edit source](/index.php?title=Power_bloc_modding&action=edit&section=10 "Edit section: Power bloc names")\]

Power blocs have a selection of names that can be used for randomized and AI-led bloc names. These are scripted in /common/power\_bloc\_names/. Each name is a block with a trigger determining when it is valid for use as a random name.

power\_bloc\_name = {
	trigger = {	
		# Trigger evaluated in leader scope
		# scope:selected\_identity - the identity that is selected in the power bloc formation panel
	}
}

A name can be always available, for example, by simply scripting `always = yes`, more complex triggers are possible as well, such as names available only for certain countries or blocs whose leader owns a certain state.
