# Law modding

From Victoria 3 Wiki

[Jump to navigation](#mw-head) [Jump to search](#searchInput)

 

Please help with verifying or updating older sections of this article.

[Laws](/Laws "Laws") in Victoria 3 provide for making major changes to a country. Modding laws typically involves modifying several related concepts.

## Law group definition\[[edit](/index.php?title=Law_modding&veaction=edit&section=1 "Edit section: Law group definition") | [edit source](/index.php?title=Law_modding&action=edit&section=1 "Edit section: Law group definition")\]

Law groups provide certain basic details for laws, such as enactment time and chance of movements. For each law group, only a single law can be active at a time.

Law groups are defined in /Victoria 3/game/common/law\_groups. The basic definition is a script name, category, and movement chances. For example:

lawgroup\_taxation = {
	law\_group\_category = economy
	
	progressive\_movement\_chance = 1.5
	regressive\_movement\_chance = 0.15
}

The three categories are `power_structure`, `economy`, and `human_rights`. Script names can be anything and the script name also generates localization keys: `[script name]` and `[script_name]_desc`. The law group is used for ideologies as well as triggers, so a clear, but unique name is good to use.

The movement chances are multipliers to the base chance for a movement to form related to laws in this group.

Additional characteristics can be scripted for each law group:

Characteristic

Description

Value type

base\_enactment\_days

Changes the default number of days between enactment checks  
Default amount is set by define: LAW\_ENACTMENT\_DEFAULT\_BASE\_DAYS

integer

enactment\_approval\_mult

Changes the amount of approval affected by law changes in this group

float

affected\_by\_regime\_change

Laws in this group are changed by the regime change effect

boolean

change\_allowed\_trigger

Trigger block that must return true to allow manual law changes in this group

trigger block

linked\_social\_hierarchy

Laws in this group only appear for countries with the specified social hierarchy

social hierarchy

## Law definition\[[edit](/index.php?title=Law_modding&veaction=edit&section=2 "Edit section: Law definition") | [edit source](/index.php?title=Law_modding&action=edit&section=2 "Edit section: Law definition")\]

Laws are defined in /Victoria 3/game/common/laws. Each law has certain required elements and a number of optional elements. A basic definition requires the following: a script name, a group, an icon, a progressiveness score, a pop support value block, an ai\_will\_do trigger block, and an ai\_enact\_weight\_modifier value block

law\_no\_health\_system = {
	group = lawgroup\_health\_system
	icon = "gfx/interface/icons/law\_icons/no\_health\_system.dds"
	
	progressiveness = 0
	
	# AI shouldn't try to abolish institutions
	ai\_will\_do = {
		always = no
	}

	ai\_enact\_weight\_modifier = { #Petitions
		value = 0
		
		if = {
			limit = { ai\_has\_enact\_weight\_modifier\_journal\_entries = yes }
			add = 750
		}
	}
}

Like law groups, the script name can be anything and generates the localization keys `[script_name]` and `[script_name]_desc`

Laws may have additional blocks and elements as well:

Element

Description

group

which law group this law belongs to

icon

Path to a .dds image file

progressiveness

an integer that rates laws relative to each other; used for other script

modifier

a modifier block added by the law

institution

[institution](/Institution_modding "Institution modding") enabled by the law

institution\_modifier

a modifier block added to the institution enabled by the law

unlocking\_technologies

a list of [technologies](/Technology_modding "Technology modding") that must be researched to enact the law  
functionally a trigger shorthand for "has any of these technologies"

unlocking\_laws

a list of laws, one of which must be enacted to enact this law  
functionally a trigger shorthand for "has any of these laws"  
used with base laws

requires\_law\_or

a list of laws, one of which must be enacted to enact this law  
functionally a trigger shorthand for "has any of these laws"  
used with variant laws

disallowing\_laws

a list of laws which block enacting this law  
functionally a trigger shorthand for "has none of these laws"

can\_enact

a trigger block that must return true to enact this law

parent

another law which provides ideology stances to this law; this law also counts as a variant of the law for triggers

is\_visible

a trigger block that must return true for this law to appear in the list of laws for a country

on\_enact

an effect block that is done when the law is successfully enacted

on\_activate

an effect block that is done when the law becomes the active law for any reason  
fired in addition to on\_enact, when successfully enacted

on\_deactivate

an effect block that is done when the law stops being the active law for any reason

tax\_modifier\_\[level\]

a modifier block that adds effects to the given taxation level  
Levels are `very_low`, `low`, `medium`, `high`, and `very_high`

can\_impose

a trigger block which determines whether a country can impose this law on another

ai\_impose\_chance

a script value that determines how likely the AI is to impose this law when it can

ai\_will\_do

a trigger block which determines whether the AI will try to enact this law

ai\_enact\_weight\_modifier

a script value that dermines how likely the AI is to try to enact this law
