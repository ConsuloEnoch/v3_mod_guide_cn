# Institution modding

From Victoria 3 Wiki

[Jump to navigation](#mw-head) [Jump to search](#searchInput)

 

Please help with verifying or updating older sections of this article.  
At least some were last verified for [version](/Victoria_3_Wiki:Versioning "Victoria 3 Wiki:Versioning") 1.11.

[Institutions](/Institutions "Institutions") in Victoria 3 are a mechanism for applying [modifiers](/Modifier_modding "Modifier modding") to incorporated states. Modding institutions generally involves modifying several related concepts.

## Institution definition\[[edit](/index.php?title=Institution_modding&veaction=edit&section=1 "Edit section: Institution definition") | [edit source](/index.php?title=Institution_modding&action=edit&section=1 "Edit section: Institution definition")\]

Institutions are defined in /Victoria 3/game/common/institutions. The basic definition is a script name, icon, background texture, and an optional base modifier. For example:

institution\_home\_affairs = {
	icon = "gfx/interface/icons/institution\_icons/home\_affairs.dds"
	background\_texture = "gfx/interface/illustrations/institutions/home\_affairs.dds"
	modifier = {
		country\_revolution\_progress\_mult = -0.1
		country\_secession\_progress\_mult = -0.1
	}
}

All other characteristics of institutions are defined or scripted in other files.

## Institution level\[[edit](/index.php?title=Institution_modding&veaction=edit&section=2 "Edit section: Institution level") | [edit source](/index.php?title=Institution_modding&action=edit&section=2 "Edit section: Institution level")\]

Institution levels limits are set in /Victoria 3/game/common/defines/00\_defines.txt, with `MIN_INSTITUTION_INVESTMENT` and `MAX_INSTITUTION_INVESTMENT`, which are set to 1 and 5 in unmodified Victoria 3. The maximum level is also limited by modifier `country_[institution_script_name]_investment_add`, which must be defined in /Victoria 3/game/common/modifier\_type\_definitions. For example:

country\_institution\_home\_affairs\_max\_investment\_add={
	decimals=0
	color=good
	game\_data={
		ai\_value=0
	}
}

In unmodified Victoria 3, this modifier is used in [technologies](/Technology_modding "Technology modding") and [laws](/Law_modding "Law modding"), but it can be applied anywhere a modifier is used.

The speed of changing from one level to another is set by the define `DAILY_INSTITUTION_SIZE_CHANGE`. The modifiers `country_institution_size_change_speed_mult` or defined institution specific modifiers `country_institution_size_change_speed_[institution_script_name]_mult` can affect that as well.

## Institution cost\[[edit](/index.php?title=Institution_modding&veaction=edit&section=3 "Edit section: Institution cost") | [edit source](/index.php?title=Institution_modding&action=edit&section=3 "Edit section: Institution cost")\]

The [![Bureaucracy](/images/thumb/7/75/Hud_bureaucracy.png/24px-Hud_bureaucracy.png)](/Capacity#Bureaucracy "Bureaucracy") bureaucracy cost of institutions per level is defined as 1 times `STATE_BUREAUCRACY_POP_MULTIPLE`. There is also a minimum cost defined by `MINIMUM_INVESTMENT_COST`. This cost can be modified by the modifiers `country_bureaucracy_investment_cost_factor_mult` or defined institution specific modifiers `country_institution_cost_[institution_script_name]_mult`. The modifier `state_bureaucracy_population_base_cost_factor_mult` also affects the cost by changing the effective amount of `STATE_BUREAUCRACY_POP_MULTIPLE`.

## Institution modifier\[[edit](/index.php?title=Institution_modding&veaction=edit&section=4 "Edit section: Institution modifier") | [edit source](/index.php?title=Institution_modding&action=edit&section=4 "Edit section: Institution modifier")\]

In addition to the defined modifier, other modifiers can be dynamically added to an institution. An institution can even have entirely dynamic effects by omitting a base modifier and only using added modifiers.

Additional modifiers are added to an institution as follows:

institution = institution\_home\_affairs	#which institution is affected
institution\_modifier = {				#what modifiers are added
	state\_conscription\_rate\_add = 0.005
	political\_movement\_radicalism\_mult = -0.05
}

Keep in mind that these modifiers are multiplied by the institution's level, just as a base defined modifier is, and that all state-related modifiers only affect incorporated states. In unmodified Victoria 3, additional modifiers are only used with laws or power bloc's principles, and it is unclear whether they can be applied in other ways.

## Enabling institutions\[[edit](/index.php?title=Institution_modding&veaction=edit&section=5 "Edit section: Enabling institutions") | [edit source](/index.php?title=Institution_modding&action=edit&section=5 "Edit section: Enabling institutions")\]

In unmodified Victoria 3, all institutions are enabled through laws. Enabling an institution in a law simply requires the script line: `institution = [institution_script_name]`. This can be followed by an institution\_modifier block as above, or alone. It is unclear whether institutions can be enabled in any other way.
