# Interest group modding

From Victoria 3 Wiki

[Jump to navigation](#mw-head) [Jump to search](#searchInput)

 

Please help with verifying or updating older sections of this article.  
At least some were last verified for [version](/Victoria_3_Wiki:Versioning "Victoria 3 Wiki:Versioning") 1.11.

*See also: [Interest groups](/Interest_groups "Interest groups")*

**Interest groups** (often abbreviated as IG) represent common socio-political interests. Each interest group has a number of [ideologies](/index.php?title=Ideology_modding&action=edit&redlink=1 "Ideology modding (page does not exist)"), three traits, and a number of other characteristics.

## Example definition\[[edit](/index.php?title=Interest_group_modding&veaction=edit&section=1 "Edit section: Example definition") | [edit source](/index.php?title=Interest_group_modding&action=edit&section=1 "Edit section: Example definition")\]

Interest groups are defined in common/interest\_groups.

Example interest group definition: 

ig\_example = {
	color = hsv{ 0.09 0.29 0.39 } # HSV for IG icon
	texture = "gfx/interface/icons/ig\_icons/armed\_forces.dds" # Texture for IG icon
	layer = "revolution\_dynamic\_armed\_forces" #refers to map graphics for revolutions
    index = 0 #relative ordering of IG, 0-indexed should be unique
    
	ideologies = { # Base ideologies for this IG
		ideology\_jingoist
		ideology\_loyalist
		ideology\_patriotic
	}

	character\_ideologies = { #default ideologies avaiable to characters affiliated with this IG
		ideology\_moderate
		ideology\_orleanist
		ideology\_bonapartist
	}
    
	enable = {  #Country scope, checks monthly, enables IG when true, disables it when false
		# enable allows for setting a condition to enable an IG for specific countries and under certain condition
		# 
		# by default it is set to always = yes for all IGs in basegame.
		#
		# A note about triggers is that any trigger which is a dynamic condition (such as army\_size = 10)
		# will not be checked until the first month of the game ends.
		#
		# Some of your IGs may thus be missing at game-start.
		# 
		always = yes
	}
    
	# Deprecated; use on\_enable effect to assign traits instead
	traits = {  # IG traits provide a bonus or malus depending on the IG approval. Definitions go in common/interest\_group\_traits
		ig\_trait\_patriotic\_fervor
		ig\_trait\_veteran\_consultation
		ig\_trait\_materiel\_waste
	}	
	
	on\_enable = {} #Country scope, fires when an IG is enabled
	on\_disable = {} #Country scope, fires when an IG is no longer enabled, because the enable trigger evaluated to false.
    
	priority\_cultures = { #sets cultures for generated characters affiliated with this IG, defaults to primary cultures of country otherwise
		rule = { #Repeat block for each set of rules (different culture lists)
			trigger = { #Country scope
				<triggers>
			}
			cultures = {
				<list of culture keys>
			}
		}
	}
    
	on\_character\_ig\_membership = { # Triggered when a major character becomes an IG member.
		change\_character\_religion = scope:interest\_group.owner.religion
	} 
	
	pop\_potential = { #Pop scope, Defines which pops are ALLOWED TO join the IG
		OR = {
			is\_pop\_type = soldiers
			is\_pop\_type = officers
			is\_pop\_type = aristocrats
			pop\_is\_discriminated = no
		}		
	}
	
	pop\_weight = { #Pop scope, defines the likelihood (weight) certain pops are to join the IG; uses script values
		value = 0
		
		add = {
			desc = "POP\_NOT\_DISCRIMINATED"
			if = {
				limit = { 
					pop\_is\_discriminated = no
				}
				value = 25
			}
		}		

		add = {
			desc = "POP\_SOLDIERS"
			if = {
				limit = { 
					is\_pop\_type = soldiers
				}
				value = 100
			}
		}
		
		add = {
			desc = "POP\_ARISTOCRATS"
			if = {
				limit = { 
					is\_pop\_type = aristocrats
				}
				value = 50
			}
		}		
	
		add = {
			desc = "POP\_OFFICERS"
			if = {
				limit = { 
					is\_pop\_type = officers
				}
				value = 200
			}
		}
					
		multiply = {
			desc = "LEADER\_POPULARITY"
			scope:interest\_group = {
				leader = {
					value = popularity
					multiply = 0.0025
					add = 1
					max = 1.25
					min = 0.75
				}
			}
		}	
	}
	
    # Character weights are the likelihood (weight, multiplied by clout) that this type of character is affiliated with the IG; uses script values
	monarch\_weight = { #IG scope, for monarch or heir
		value = 0.25
	}
	
	commander\_weight = { #? scope, for general or admiral
		value = 5.0
	}

	agitator\_weight = { #Character scope
		value = 0.0
	}
    
	executive\_weight = { #? scope
		value = 0.0
	}
	
	noble\_chance = { #chance that character uses a noble name rather than a common name
		value = 0.5
	}
	
	female\_commander\_chance = { #chance of female character in this role
		value = 0.0
	}
	
	female\_politician\_chance = { #chance of female character in this role
		value = 0.0
	}

	female\_executive\_chance = { #chance of female character in this role
		value = 0.0
	}
	
	# The chance that a commander belonging to this IG takes over leadership when it changes
	# scope:character is the most popular commander in the IG
	commander\_leader\_chance = {
		value = 0.75
		if = {
			limit = {
				exists = scope:character
			}
			multiply = {
				value = 1
				add = scope:character.popularity
				min = 0
			}
		}
	}
    # The chance that a executive belonging to this IG takes over leadership when it changes
	# scope:character is the most popular executive in the IG
	executive\_leader\_chance = {
		value = 0.1
	}
}

## Interest group traits\[[edit](/index.php?title=Interest_group_modding&veaction=edit&section=2 "Edit section: Interest group traits") | [edit source](/index.php?title=Interest_group_modding&action=edit&section=2 "Edit section: Interest group traits")\]

Interest group traits are defined in common/interest\_group\_traits. They consist of a script name, an icon, a minimum approval, and a [modifier](/Modifier_types "Modifier types") block.

ig\_trait\_patriotic\_fervor = {
	icon = "gfx/interface/icons/ig\_trait\_icons/patriotic\_fervor.dds"
	min\_approval = loyal

	modifier = {
		unit\_offense\_mult = 0.1
		unit\_defense\_mult = 0.1
	}
}

ig\_trait\_veteran\_consultation = {
	icon = "gfx/interface/icons/ig\_trait\_icons/veteran\_consultation.dds"
	min\_approval = happy

	modifier = {
		country\_military\_tech\_research\_speed\_mult = 0.1
	}
}

ig\_trait\_materiel\_waste = {
	icon = "gfx/interface/icons/ig\_trait\_icons/materiel\_waste.dds"
	max\_approval = unhappy

	modifier = {
		country\_military\_goods\_cost\_mult = 0.15
	}
}
