### Diplomatic actions\[[edit](/index.php?title=Diplomacy_modding&veaction=edit&section=1 "Edit section: Diplomatic actions") | [edit source](/index.php?title=Diplomacy_modding&action=edit&section=1 "Edit section: Diplomatic actions")\]

The relevant documents can be found in the diplomatic\_actions folder in `/Victoria3/game/common/diplomatic_actions`. Each type of action has its own file.

### Diplomatic plays\[[edit](/index.php?title=Diplomacy_modding&veaction=edit&section=2 "Edit section: Diplomatic plays") | [edit source](/index.php?title=Diplomacy_modding&action=edit&section=2 "Edit section: Diplomatic plays")\]

The relevant document can be found in the diplomatic\_plays folder in `/Victoria3/game/common/diplomatic_plays`. All types of diplomatic plays are saved in the same save game file.

### Secret Goals\[[edit](/index.php?title=Diplomacy_modding&veaction=edit&section=3 "Edit section: Secret Goals") | [edit source](/index.php?title=Diplomacy_modding&action=edit&section=3 "Edit section: Secret Goals")\]

The AI can be guided towards certain behaviors towards other nations by using `set_secret_goal` and `set_mutual_secret_goal`. The following are known secret goals:

-   antagonize
-   befriend
-   conquer
-   dominate
-   none
-   protect
