# Event target

From Victoria 3 Wiki

*This page discusses the game script element called "event targets". For pop-up narrative content events, see [Event modding](/Event_modding "Event modding"); for lists and details of events that exist in Victoria 3, see [Events](/Events "Events").*

**Event targets** are object, [scope](/Scope "Scope"), or value references used in Victoria 3's game script. Most event targets can be used as target of an [effect](/Effect "Effect") or [trigger](/Trigger "Trigger") when it refers to an appropriate scope, object, or value. Similarly, event targets can be used as scopes or the left side of a value comparison.

Event targets that represent scopes can generally be used in dot chains as for example: `p:xF98DA3.state.owner.capital` which looks at the specified province, then chains to that province's state, that state's owning country, and finally to that country's capital state.

## Data event targets\[[edit](/index.php?title=Event_target&veaction=edit&section=1 "Edit section: Data event targets") | [edit source](/index.php?title=Event_target&action=edit&section=1 "Edit section: Data event targets")\]

These event targets require additional input, such as a scripted type or specified scope. This generally takes the form of `event_target:data`; some use the format `event_target(data)`, this type must be enclosed in quotation marks, including any dot scoped elements, e.g. `"scope:power_bloc.power_bloc_leader.market.market_number_goods_shortages_with(scope:with_country)"`.
