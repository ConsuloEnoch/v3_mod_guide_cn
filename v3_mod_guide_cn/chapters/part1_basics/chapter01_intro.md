## 1.1 什么是Mod？

**Mod**（Modifications的缩写）意为"游戏修改"。简单来说，Mod就是玩家或开发者对游戏进行的自定义修改。

### 生活化比喻

想象你买了一套乐高积木，官方给了你一本说明书教你如何搭建城堡。但你觉得城堡不够酷，想要：
- 给它加上吊桥和护城河
- 把城堡变成太空基地
- 或者干脆自己设计一座全新的建筑

Mod就相当于你对乐高城堡做的这些自定义改造。

### 在维多利亚3中

维多利亚3是一款由Paradox Interactive开发的 grand strategy 游戏，玩家扮演19世纪的国家统治者，管理经济、政治、外交和军事。

**官方游戏**就像一本历史教科书，讲述着1836-1936年间"可能发生的故事"。而**Mod**则允许你：

- **修正历史**：如果清朝没有闭关锁国会怎样？
- **创造新内容**：添加新的国家、事件、科技
- **改变玩法**：让游戏更符合你的喜好

> 💡 **提示**：Paradox游戏以支持Mod著称，维多利亚3也不例外。许多流行的Mod（如历史修正Mod、画质增强Mod）都来自社区创作者。

## 1.2 Mod能做什么？

### 1.2.1 历史修正类

这是最受欢迎的Mod类型之一。它们修改游戏的初始设置，让你体验"如果历史这样发展"的情景。

**示例**：
- 让清朝提前开始现代化改革
- 阻止美国内战爆发
- 让某个国家提前统一或独立

### 1.2.2 新增内容类

这类Mod为游戏添加全新的内容。

**可以添加的内容**：

| 类型     | 说明               | 示例                     |
| -------- | ------------------ | ------------------------ |
| **国家** | 创建新的可玩国家   | 江南共和国、西域汗国     |
| **事件** | 添加历史或虚构事件 | 太平天国起义、工业革命   |
| **决策** | 添加国家战略决策   | 推行洋务运动、废除农奴制 |
| **科技** | 添加新的科技树     | 电力时代、航空技术       |
| **法律** | 添加新的政体或制度 | 君主立宪制、联邦制       |
| **建筑** | 添加新建筑类型     | 银行、博物馆             |
| **商品** | 添加新的贸易商品   | 茶叶、香料               |

### 1.2.3 玩法修改类

这类Mod改变游戏的核心机制。

**常见修改**：
- 调整经济系统（让贸易更真实或更简单）
- 修改AI行为（让电脑更聪明或更具挑战性）
- 改变战争系统
- 调整人口增长率

### 1.2.4 视觉增强类

改善游戏的画面表现。

**包括**：
- 高清纹理包
- 新旗帜设计
- 界面美化
- 新模型和动画

### 1.2.5 实用工具类

帮助玩家更好地体验游戏。

**示例**：
- 控制台命令扩展
- 信息显示增强
- 自动化工具

## 1.3 维多利亚3 Mod的独特之处

相比其他游戏，维多利亚3的Mod系统有以下几个特点：

### 1.3.1 纯脚本驱动

维多利亚3使用**脚本语言**而非传统编程语言。这意味着：

✅ **优点**：
- 不需要编程基础就能入门
- 语法相对简单直观
- 修改即时生效，无需编译

⚠️ **限制**：
- 无法实现复杂的新机制
- 受限于游戏提供的脚本接口
- 无法修改游戏底层代码

### 1.3.2 高度模块化

Mod文件采用**覆盖式加载**：

```pdx
游戏本体文件 → Mod文件（同名覆盖） → 加载顺序决定最终效果

```

这允许多个Mod同时工作，但也可能导致冲突。

### 1.3.3 丰富的游戏对象

维多利亚3拥有20+种**作用域**（Scope）类型：

- `country`（国家）
- `state`（州/省份）
- `pop`（人群）
- `building`（建筑）
- `character`（角色）
- 等等...

每种对象都有专属的触发器（Triggers）和效果（Effects），提供了极大的创作自由度。

## 常见问题

**Q：我需要会编程才能做Mod吗？**

A：不需要！维多利亚3使用脚本语言，比传统编程简单得多。本书专门为零基础的读者编写，会一步步带你入门。

**Q：做Mod会损坏我的游戏吗？**

A：不会。Mod是独立加载的，不会影响游戏本体文件。即使Mod有问题，也只会影响那个Mod本身，不会损坏游戏。

**Q：我可以从别人的Mod中学习吗？**

A：可以！这是学习Mod开发的最佳方式之一。Steam创意工坊下载的Mod文件可以在本地查看，但要注意尊重原作者的版权。

**Q：我需要购买DLC才能做Mod吗？**

A：不需要。基础游戏就足够学习和制作Mod了。当然，如果你想修改DLC内容，需要有相应的DLC。

**Q：制作一个完整的Mod需要多长时间？**

A：这取决于复杂度：
- 简单的事件Mod：1-2小时
- 完整的历史修正Mod：几天到几周
- 大型总转换Mod：数月到数年
