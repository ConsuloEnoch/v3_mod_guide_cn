## 📝 写作规范

### 每章标准结构

```markdown
# 第X章：章节标题

## 本章目标
（学习本章后你能做什么，3-5条）

## 概念讲解
（核心知识，配比喻和图解）

## 详细说明
（技术细节，分节讲解）

## 实战案例
（完整可运行的代码）

## 常见问题
（3-5个FAQ）

## 本章小结
（3-5条要点总结）

## 练习建议
（可选的动手练习）

```

```markdown

```pdx
# 这是示例代码

}

```pdx

| 参数         | 类型 | 说明           | 示例 |
| ------------ | ---- | -------------- | ---- |
| add_treasury | int  | 增加的国库金额 | 1000 |
